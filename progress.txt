### BUG-004: Remove unused texture uniforms from shader
- **Status:** COMPLETED
- **Date:** 2026-01-24
- **Changes:** Removed unused `normalTexture` and `specularTexture` that were loaded but never used in the fragment shader:
  - Removed texture loading for `textures/earth_normal.jpg` and `textures/earth_specular.jpg`
  - Removed `normalTexture` and `specularTexture` uniforms from ShaderMaterial
  - Removed unused uniform declarations from fragment shader
  - This reduces bandwidth usage and eliminates unnecessary texture downloads

### BUG-005: Cache DOM element references for performance
- **Status:** COMPLETED
- **Date:** 2026-01-24
- **Changes:** Cached the 'currentTime' DOM element reference to avoid repeated getElementById calls:
  - Added `timeDisplayElement` global variable to store the cached reference
  - Modified `initTimeControls()` to cache the element reference during initialization
  - Updated `updateTimeDisplay()` to use the cached reference instead of calling `document.getElementById('currentTime')` on every update
  - This eliminates unnecessary DOM queries during slider movement for improved performance
